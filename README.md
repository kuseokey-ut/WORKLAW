# WORK.LAW — Трудовые отношения

15 ситуаций по трудовому праву. Варианты ответа перемешаны: правильный ответ не закреплён за одной буквой. Ситуации сделаны менее «учебниковыми»: в них есть конкурирующие правдоподобные позиции, нюансы оформления и различия между похожими правовыми конструкциями.

## GitHub Pages
Загрузи содержимое папки в публичный репозиторий → Settings → Pages → Deploy from a branch → main → / (root).

## Примечание
Проект учебный. Перед использованием сверяй нормы с актуальной редакцией ТК РФ.


## Рандомизация
При каждом запуске симуляции:
- 15 кейсов автоматически перемешиваются в новом порядке;
- варианты ответа внутри каждого кейса тоже перемешиваются;
- правильный ответ поэтому не закреплён за одной буквой;
- кнопка «Начать заново» создаёт новую случайную последовательность.
